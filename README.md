# oaqjp-final-project-emb-ai

## Emotion Detection Web Application

This repository contains the **Final Project** for the IBM AI-Based Web Application Development course.

### Project Name: oaqjp-final-project-emb-ai

The project is an **Emotion Detection** web application built using:
- IBM Watson NLP Embedded AI Libraries
- Python (Flask framework)
- HTML/CSS/JavaScript frontend

### Project Structure

```
EmotionDetection/
    __init__.py
    emotion_detection.py
templates/
    index.html
static/
    mywebscript.js
server.py
test_emotion_detection.py
```

### Tasks Completed

1. **Task 1** – Cloned the project repository
2. **Task 2** – Created the Emotion Detection application using Watson NLP library
3. **Task 3** – Formatted the application output
4. **Task 4** – Packaged the application as `EmotionDetection`
5. **Task 5** – Ran unit tests on the application
6. **Task 6** – Deployed the web application using Flask
7. **Task 7** – Incorporated error handling
8. **Task 8** – Ran static code analysis (pylint score: 10/10)

### How to Run

```bash
python3.11 server.py
```

Then open your browser at `http://localhost:5000`
